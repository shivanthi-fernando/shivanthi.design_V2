# Shivanthi's portfolio — working notes

Main working file: `Portfolio v2.dc.html` (all recent work lives here). Older: `Portfolio.dc.html` (laptop-sticker hero), `Portfolio v1.dc.html` (snapshot). Design system: `Design System.dc.html`.
Theme: scrapbook-inspired editorial collage. Palette: blush pink, lilac, kraft brown, cocoa, ink (#221C1E) on warm white #FCFAF7 with faint grid. No green/yellow/blue (exceptions: brand colours on social icons; For You gift stickers use bright fun colours — coral, sunny yellow, sky, violet, mint, blue, indigo — no pink/brown).

## Hard rules from the user
- Never use block letters: no uppercase text, no "Chapter 01 · Hello"-style labels.
- Never use DM Mono or any monospace font. Fonts: Caveat Brush (headings, name, labels), Shantell Sans (body, small text).
- Headings all black ink; section titles sit on a pink washi-tape strip.
- Stickers: die-cut look (cream #FCF3E2 rim + soft cocoa shadow), cartoon style, thick ink outlines.
- Pencil-sketched arrows (graphite #4A3F42); hint notes in brown Caveat Brush (#8C735F).
- Selected nav = pink #D9628F pencil circle.
- Buttons: primary = light lilac #E6DCF3 sticker pill (no tilt); secondary = outline pill, warm-white fill; tertiary = kraft gift tag.
- Small, targeted changes only; user gives precise nudges ("a little bit"). Keep user copy verbatim.
- No scrollbars inside sections (user dislikes them).
